##### 논문 요약

방송사는 하나의 원본을 모바일, OTT, 소셜미디어용 하이라이트와 숏폼으로 다시 만들어야 하지만, 긴 영상에서 핵심 장면을 찾고 구간을 지정하는 일은 여전히 사람의 수작업에 의존합니다.

이 논문은 새로운 탐지 모델을 만드는 대신, **오픈소스 멀티모달 AI 분석** 과 **방송사의 편성·경기 메타데이터** 를 실제 제작 프로세스에 연결하는 통합 구조를 제안합니다. AI가 클립 초안을 만들고, 운영자는 검수와 보정에 집중하는 방식입니다.

##### 핵심 기여

- **방송 메타데이터 융합 구조** : 프로그램·회차·경기 정보를 의미 단위 청킹의 기준이자 구간 검색의 필터로 활용
- **Human-in-the-loop 검수 체계** : 생성 구간을 원본 시간축에서 검증하고, 운영자 수정 이력을 평가 데이터로 환류
- **정량 평가 프로토콜** : tIoU 기반으로 정밀도·재현율·F1과 경계 오차를 측정하는 평가 방법 정의

##### 시스템 구성

솔박스 분석 코어가 영상·음성·OCR·자막에서 구조화된 장면 정보를 생성하고, SBSI가 메타데이터 연동, 구간 검증, 클립 생성, 서비스 연계를 담당합니다.

1. **멀티모달 인덱싱** : 화자 분리, 음성 인식, 장면 전환 탐지, VLM 장면 설명
2. **시간 정렬 및 의미 단위 청킹** : 원본 시간축 기준으로 정렬하고, 대사 연속성과 경기 맥락으로 장면 병합
3. **구간 검색 및 후보 생성** : 벡터 검색과 메타데이터 필터, RAG로 클립 후보 구성
4. **클립 생성 및 운영자 검수** : 자동 컷팅 후 운영자 확인을 거쳐 서비스 반영

사용한 오픈소스 상세는 [오픈소스 기여] 페이지를 참고해 주세요.

##### 실증 결과

2026 아이치·나고야 아시안게임 야구 종목에 적용해 실증을 완료했습니다.

- 대한민국 대표팀 **5경기** 에서 **79개 하이라이트 클립** 을 자동 생성해 SBS play ‘AI PICK’에 게시
- 초기 적용 경기에서 생성 클립이 **약 10% 수준의 미세 수정** 만 거쳐 서비스에 반영
- 기존 수작업은 클립 1건당 약 18분이 걸리던 작업으로, 이를 검수 중심으로 전환

79개 클립 전체에 대한 정량 평가를 진행 중이며, 이후 다른 종목과 드라마등으로 콘텐츠로 확장할 계획입니다.
