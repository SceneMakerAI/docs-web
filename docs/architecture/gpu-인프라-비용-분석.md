### 1. 개요

SceneMaker 의 추론 계층(vLLM 기반 텍스트 LLM·VLM·임베딩, GPU 워커)을 클라우드에서 운영할 때의 비용을 산정한다.

AWS·Azure·GCP 의 주요 GPU 인스턴스를 같은 기준으로 비교하고, 상시 가동 기준 월 비용을 원화로 정리한다.

---

### 2. 산정 기준

| 항목 | 기준 |
| --- | --- |
| 요금 유형 | 온디맨드(On-Demand), Linux, 약정·할인 미적용 |
| 기준 리전 | **서울 → 도쿄 → 미국 동부** 순. 서울에 없는 인스턴스만 다음 순서 리전 단가 적용 |
| 스토리지 | 인스턴스 비용과 별도 산정 (3.2 참조) |
| 환율 | **1 USD = 1,400 원** (환율 변동을 감안한 보수적 기준. 2026년 10월 말 서울 외환시장 기준가는 약 1,338원) |
| 계산식 | 월 비용(원) = 시간당 단가 × 30일 × 환율, 천 원 단위 반올림 |

스토리지(EBS)는 인스턴스를 중지해도 과금되므로 가동 시간과 무관하게 인스턴스당 월 전액을 별도로 더한다. 네트워크 송신(egress)·스냅샷·S3 비용은 제외했다.

### 4. 분석

##### 4.1 단가 효율

| 지표 | 최저 | 최고 | 비고 |
| --- | --- | --- | --- |
| USD / GPU·h | GCP L4 $1.28 · AWS A100 $4.70 · AWS g7e $4.92 | Azure H100(ND96isr) $16.59 | GPU 세대·VRAM 이 달라 단순 비교 주의 |
| USD / VRAM GB·h | g7e.4xlarge $0.051 · g7e.12/24xlarge $0.053 · g2 $0.054 | Azure ND96isr $0.207 | 추론(모델 상주)은 이 지표가 더 중요 |

##### 4.2 주요 판단

1. **추론 서버는 AWS g7e 계열**
    단일 GPU 96GB 를 서울에서 시간당 $4.92 에 쓸 수 있어 H100 단일 GPU(p5.4xlarge, 80GB, 도쿄 $8.60) 대비 약 43% 저렴.  
   Qwen 계열 텍스트 LLM·Qwen3-VL·임베딩을 GPU 별로 나눠 상주시키는 현재 구조에 적합

2. **H100 8장급은 AWS 가 가장 저렴**
   AWS 가 2025년 6월 P5 요금을 약 44% 인하하면서, 서울 기준 p5.48xlarge 는 Azure ND96isr 의 57%, GCP a3-highgpu 의 67% 수준. 파인튜닝·대형 모델 학습이 필요할 때만 단기 사용 권장

3. **g7e 다중 GPU 는 TP 성능을 확인**
   RTX PRO 6000 은 NVLink 가 없어 12xlarge·24xlarge 에서 텐서 병렬 시 PCIe 로 통신. 모델을 GPU 하나에 올리고 인스턴스를 수평 확장하는 방식

### 5. 비용 절감 옵션 (AWS)

| 옵션 | g7e.4xlarge | p5.48xlarge | 조건 |
| --- | --- | --- | --- |
| 온디맨드 | $3.998/h | $55.04/h | 약정 없음 |
| EC2 Instance Savings Plan 1년 | $2.519/h (−37%) | 약 $38.53/h (−30%) | 1년 약정, 무선결제 |
| EC2 Instance Savings Plan 3년 | $1.727/h (−57%) | 약 $24.77/h (−55%, 3년 RI) | 3년 약정 |
| Capacity Block | — | $34.608/h | 기간 예약, 선결제, 용량 보장 |
| Spot | 약 $1.7/h | 가용성 불안정 | 중단 허용 배치 작업만 |

위 금액은 **us-east-1 기준** 이며 할인율 참고용이다. 서울 리전은 g7e Spot 할인 폭이 약 10% 수준으로 작아 Spot 효과가 제한적이다. 

서울 약정 단가는 AWS Pricing Calculator 로 별도 확인필요.

상시 가동이 확정된 추론 서버는 Savings Plan, 비정기 학습은 Capacity Block, 재시도 가능한 분석 배치는 Spot 을 검토

### 6. 유의사항

- 고성능 GPU(P5·ND·A3)는 온디맨드로도 용량 확보가 안 되는 경우가 잦아 쿼터 신청이 선행 필요
- 가격은 공개 요금표 기준이며 각 사 요금 변경·환율에 따라 달라짐. 정확한 확정 예산은 각 사 Pricing Calculator 로 재확인 필요.
- 환율은 보수적으로 1,400원을 적용
- 도쿄 리전 단가를 적용한 p4de.24xlarge·p5.4xlarge 는 서울 리전에서 제공되지 않으므로, 서울 내 다른 자원과 연동 시 리전 간 데이터 전송 비용·지연을 고려해야함.
