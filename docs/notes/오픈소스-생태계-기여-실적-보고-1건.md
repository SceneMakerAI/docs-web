### 들어가며

---

![image](/img/notes/오픈소스-생태계-기여-실적-보고-1건/img-00.jpg)

- 다른 개발자가 참여한 기여는 **31건** 이다. Pull Request 14건, Issue 10건, Discussion 7건이다. 과제의 목표는 30건이다.
- Pull Request 14건은 모두 머지됐고, 그중 **11건은 이미 배포 버전에 들어갔다.** 나머지 3건은 해당 프로젝트가 다음 버전을 내면 들어간다.
- 머지를 기다리는 Pull Request 가 17건 더 있다. 머지되기 전이라 위 숫자에 넣지 않았다.

---

#### 1. 무엇을 기여로 세나

기여를 셀 때는 **다른 개발자가 실제로 참여한 것** 만 센다. 올리기만 하고 아무 반응이 없는 것은 세지 않는다.

- **Pull Request:** 메인테이너가 검토하고 머지한 것
- **Issue:** 메인테이너가 해결로 닫았거나, 다른 개발자가 원인을 함께 보거나 수정을 맡은 것
- **Discussion:** 메인테이너나 다른 개발자가 답한 것

검토 중인 Pull Request 17건과, 머지 없이 닫힌 Pull Request 5건은 세지 않는다. 진행 중인 외부 Issue 2건(다른 개발자가 수정 PR 을 올려 검토 중)까지 빼고 결과가 난 것만 보면 29건이다.

---

#### 2. 파이프라인이 쓰는 도구에서 나왔다

기여할 곳을 따로 찾지 않았다. 기여한 저장소는 모두 SceneMaker 파이프라인이 실제로 쓰는 도구다.

![image](/img/notes/오픈소스-생태계-기여-실적-보고-1건/img-01.jpg)

- **음성:** 받아쓰기(faster-whisper, whisper), 언어 판별(SpeechBrain), 오디오 파일 읽기(python-soundfile)
- **화면:** 컷 분할(PySceneDetect), 프레임 이미지 처리(Pillow)
- **추론:** 모델 서빙(vLLM), 모델 호출(LiteLLM)
- **색인:** 벡터 검색(Milvus)
- **서비스:** API 서버(Starlette, Uvicorn, AnyIO), 설정과 검증(pydantic, pydantic-settings), DB 접속(PyMySQL)

직접 쓰는 도구라 문제가 실제로 일어나는 조건을 알고 있었고, 그것이 재현 예와 테스트를 만드는 데 그대로 쓰였다.
