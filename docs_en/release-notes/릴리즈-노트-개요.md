This is where version-by-version changes for SceneMakerAI's four services (**Highlights · Remix · Ad · Batch**) are collected.

> 🚧 Pre-first-release. Entries will be added to this index at release time.

## **What's covered**

- **SemVer version-based** changes for all four services — new features, behavior changes, bug fixes

- **Compatibility changes** and migration guides

- **Version changes** for dependent models/libraries (Qwen, vLLM, LangGraph, faster-whisper, etc.)

## **What's not covered**

- **Changes to the docs-web site itself** (layout, documentation edits, etc.) — managed via [GitHub Release](https://github.com/SceneMakerAI/docs-web/releases) or `git log`.

- **Small per-PR changes** — these accumulate and are included in the next minor/patch release.

## **Authoring & management rules**

File naming, ordering, body structure, and merge timing for release notes are defined in [CONTRIBUTING.md — Release Notes Rules](https://github.com/SceneMakerAI/docs-web/blob/main/CONTRIBUTING.md#8-%EB%A6%B4%EB%A6%AC%EC%A6%88-%EB%85%B8%ED%8A%B8-%EB%A3%B0).

## **Index**

As releases are added, they will accumulate in the left sidebar in reverse chronological order.
