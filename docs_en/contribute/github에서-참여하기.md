SceneMakerAI's open-source repositories are available on GitHub.

- Audio Benchmark PoC: https://github.com/SceneMakerAI/poc-audio-bench

- Vision Benchmark PoC: https://github.com/SceneMakerAI/poc-vision-bench

Visit a repository you're interested in, leave feedback via Issues, or propose improvements directly through Pull Requests.

For detailed contribution steps, refer to the **How to Contribute** page.
