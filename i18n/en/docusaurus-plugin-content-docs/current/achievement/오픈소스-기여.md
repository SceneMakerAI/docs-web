#### Terminology

- **PR · Merged**: The code changes we submitted have been reviewed by the project’s maintainer and incorporated into the official codebase. This indicates that the contribution is fully complete.
- **Included in a release**: The merged changes have been included in a version that can actually be downloaded (via `pip install`). They are included when the project releases its next version, and the release timing is determined by the project.
- **Issue · Closed as Resolved**: The maintainer has confirmed that the issue we reported has been fixed and has closed it.
- **Discussion · Reply**: A response from a maintainer or another developer to a post on the questions/suggestions board. It counts as a contribution only if a person responds.
- **Pending Review**: A pull request has been submitted and is awaiting review by a maintainer. You cannot rush this process; it takes anywhere from a few hours to several months, depending on the project.
