## Establishment of a Multimodal Scene Retrieval Evaluation System (Baseball · TV Dramas)

> 💡 **5 baseball games (4 broadcasters) · Episodes 1–10 of the drama “Manager Kim” · 26 query types · Review of approximately 40 references**
This evaluation framework measures, using the F1 score, whether scenes found via natural language queries match the correct answers. It is used for the national R&D project performance indicator “Multimodal Scene Analysis Accuracy” (F1 for scene and emotion classification based on VLM + RAG, verified by ETRI’s accredited testing).

---

### 1. Why It Was Developed

SceneMakerAI understands broadcast footage on a scene-by-scene basis and locates specific segments when users make verbal requests such as “Show me the high-scoring scenes” or “Find the scene where Manager Kim gets angry.” To measure how accurate this feature is, a standard is needed that defines “the correct answer to this query is these scenes.”

A review of domestic and international literature revealed that **there was no publicly available standard for evaluating query-based scene retrieval using F1 scores for Korean broadcast videos.** Since there are only separate benchmarks for scene segmentation, emotion recognition, sports event detection, and long-form video understanding, we combined these methods to build our own evaluation dataset (see Chapter 8 for references).

We selected these two genres with distinct characteristics for the following reasons.

| Genre | Basis for determining the correct answer | Capabilities being evaluated |
| --- | --- | --- |
| Baseball | Official game records (objective) | Recognition of scoreboards and broadcast footage, tracking game flow (ties, comebacks), conditional filtering |
| Drama | Script + labeler’s judgment | Multimodal understanding of characters, locations, dialogue, actions, and emotions |

#### 2-2. Query System (16 Types)

**Basic Queries (Q01–Q07)**

| ID | Type | Query Example | Correct Answer Generation Rule |
| --- | --- | --- | --- |
| Q01 | Run | Show me a scoring play / Show me a play where a run was scored | At-bats resulting in a run (3-run home run = 1) |
| Q02 | Hit | Show me a hit | At-bats resulting in a single, double, or triple (excluding home runs) |
| Q03 | Home Run | Show me only home run highlights | At-bats resulting in home runs |
| Q04 | Walk/Hit by Pitch | Show me walk highlights / Show me hit-by-pitch highlights | At-bats resulting in walks or being hit by a pitch |
| Q05 | Stolen Base | Show all stolen base attempts | At-bats resulting in advancement due to stolen base attempts, wild pitches, or passed balls |
| Q06 | Strikeout | Show strikeout scenes | At-bats ending in a strikeout (swinging or looking) |
| Q07 | Double Play | Show a double play | Double play play |

**Conditional Queries (C01–C04)** — Fill in the blanks with actual values from each game.

| ID | Type | Query Example | Correct Answer Generation Rule |
| --- | --- | --- | --- |
| C01 | Team + Run | Show Doosan scoring plays | Only scoring at-bats for the specified team |
| C02 | Inning + Run | Show 7th-inning scoring plays | Only scoring at-bats in the specified inning |
| C03 | Inning + Home Run | Show home run highlights from the 7th inning | Only home run at-bats in the specified inning |
| C04 | Player + Home Run | Show Yang Ui-ji’s home run highlights | Only home run at-bats by the specified player |

**Game Situation Queries (S01–S05)** — You must track score changes in chronological order to answer these.

| ID | Type | Query | Correct Answer Generation Rule |
| --- | --- | --- | --- |
| S01 | First Run | Show the first run | The at-bat that produced the game’s first run |
| S02 | Tie | Show the tie | The at-bat where the trailing team tied the score (e.g., 2:3 → 3:3) |
| S03 | Comeback | Show the comeback scene | The at-bat when the trailing team took the lead (2:3 → 4:3; includes tying the game and taking the lead) |
| S04 | Lead | Show the lead scene | At-bat where the leading team extended its lead (3:2 → 5:2) |
| S05 | Walk-off | Show the walk-off scene | At-bat in the bottom of the 9th inning or later that ended the game with a run scored by the home team |

#### 2-3. Entering the Correct Answers

- The criteria for correct answers are **official game records** (text broadcasts and batter’s box records), and batters with 1 or more RBIs are considered for scoring at-bats. The method of semi-automatically generating answers by aligning text play-by-play with video footage is similar to the approach used in BBDB (ECCV 2018).
- Each answer records the team, inning, situation, player, and **timestamp within the video**, and a reviewer double-checks the timestamp against the video.

| ID | Type | Question | Evaluation Criteria |
| --- | --- | --- | --- |
| Q08 | Recap | Please edit the video so that viewers can understand this episode’s story | SBS official clip · Degree of alignment with the plot and key events `[확인 필요: 목표 길이]` |
| Q09 | Short-form(Trailer) | Teaser scene that piques curiosity without revealing the ending | Impact · Whether the ending is revealed |
| Q10 | Advertisement | Sections suitable for inclusion as {advertising material} | Relevance between the material and the scene (e.g., alcohol → company dinner scene) |

#### 3-3. Entering Correct Answers

- Items verifiable from the script (characters, situations, locations, dialogue) are based on the **script**; items requiring judgment (actions, emotions) are entered separately by **two labelers** and then cross-checked.
- For each answer, record the location, characters, question, segment start, and segment end; the reviewer marks these with an o or x. Items marked with an x are rewritten.

### 4. Scoring Method

For both genres, the system calculates F1 by comparing the results it finds with the correct answers for each question. The unit of correctness differs between baseball (**timing**) and drama (**segment**), so the criteria for “correct” (TP) also differ.

| Genre | Correct Answer Unit | True Positive (TP) Criteria | Basis |
| --- | --- | --- | --- |
| Baseball | Time (at-bat) | **Within ± N seconds** of the correct time `[확인 필요: 예 ±10초]` | SoccerNet’s δ tolerance method |
| Drama | Interval | Overlap ratio (IoU) **at or above the threshold** `[확인 필요: 예 0.5]` | Moment Retrieval’s IoU method |

- Precision = Number of correct hits ÷ Number of hits found
- Recall = Number of correct hits ÷ Number of correct answers
- F1 = 2 × P × R ÷ (P + R)
- **Queries with 0 correct answers** (e.g., games with no double plays): If the system finds nothing, it receives 1 point; if it finds even one, it receives 0 points. `[확인 필요]`

For baseball, averages are calculated by query type (basic, conditional, game situation); for dramas, averages are calculated by episode, and then an overall average is derived. Drama queries Q08–Q10 are not included in the F1 average.

### 5. Challenges

#### 5-1. Baseball — “What the correct answer is” is clear, but “when it occurs” is ambiguous

In baseball, since **correct events**—such as hits, home runs, and strikeouts—are confirmed by official records, there is almost no disagreement regarding the content of the correct answer. The challenge lies in **determining exactly which point on the video timeline to use as the reference point for that event**.

- The moment the pitcher releases the ball
  - Since events such as hits, home runs, and strikeouts occur after the pitcher releases the ball, the moment of release is used as the reference point. 

- When the broadcast misses the moment the pitcher releases the ball
  - Occasionally, the broadcast camera misses the moment the pitcher releases the ball. In this case, the reference point is set within 3 seconds of that moment from the camera’s perspective.

#### 5-2. TV Dramas — Even “what constitutes a single scene” is subjective

In TV dramas, the specific events that constitute a “correct answer” are not defined by any fixed record. The boundaries of scenes, the interpretation of emotions, and even the number of correct answers can vary from person to person.

| Difficulty | Content | Response |
| --- | --- | --- |
| Scene boundaries are not objective | When time shifts within the same location, or when cross-cutting or flashbacks are inserted, where to cut a scene varies from person to person. Even in academic literature, the agreement rate among people regarding scene transition points was only 76.5% (MovieScenes). | Use the **scene headers** in the script as boundaries and match them using intersection of overlap (IoU) |
| Emotional interpretations often differ even among people | Even when watching the same scene, people frequently label “anger” and “sadness” differently. In public datasets, the inter-rater agreement (κ) ranged from 0.37 to 0.43 (MELD, EmoVid). There are also scenes where the outwardly expressed emotion differs from the underlying sentiment. | Two labelers independently assigned labels and reached a consensus; emotions were queried as **broad categories** such as “anger” and “sadness” |
| Differences between the script and the broadcast version | During editing, scenes may be cut or reordered, and dialogue may change due to ad-libs. The correct answer based on the script may differ from the broadcast footage. | **Review the correct answers generated from the script while watching the broadcast footage** |
| Questions with multiple correct answers | “Office scenes” appear multiple times in a single episode. If you list only one correct answer, the system will mark it as incorrect (FP) even if it correctly identifies another office scene. | Record **all** correct scenes from that episode, or narrow the question so that there is only one correct answer |
| Ambiguity in character identification | Even when a character is in the same scene, there may be moments when they are not visible on screen, and there are cases where the same character is portrayed by a different actor, such as Kim Min-ji as a baby. | Use “appears in the scene” as the criterion and note flashbacks and child actors in the remarks |
| Variation in Segment Length | Segment lengths vary widely, from a 6-second cemetery scene to a 5-minute company dinner scene, so a single IoU threshold disadvantages shorter segments. | Review results grouped by segment length `[확인 필요]` |
| Edited queries have no single correct answer | For highlight, teaser, and commercial segments, there may be “good answers,” but there is no “single correct answer.” | Evaluate relatively, separate from F1 |

#### 5-3. Common

- **Correct answers require manual work** 
- **Costs associated with building correct answers**
  - Baseball requires 50–70 correct answers per game, and dramas require 10 episodes × 10 queries, so writing and reviewing them takes a lot of time. 

  - We are streamlining the process by creating draft answers using existing materials, such as text broadcasts and scripts, so that people can focus on review.
