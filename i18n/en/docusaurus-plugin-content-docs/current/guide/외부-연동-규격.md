## Integration Details

### Video Registration/Analysis - Request

#### Request 

```text
POST http://{HOST}:{PORT}/api/v1/stt_svc
Content-Type: application/json

{
  "v_id": 202,
  "file_path": "vod/2/202.mp4",
  "title": "2026 KBO KT vs NC",
  "category": "Sports-Baseball",
  "year": 2026,
  "callback_url" : "http://sbs.co.kr/",
  "stream_mode": "N",
  "stream_id" : "20260831120000"
}
```

| Situation | HTTP | Body |
| --- | --- | --- |
| Received (vod) | 200 | `{"v_id": 202, "stream_id": "VOD", "code": 0, "result": "OK"}` |
| Received (stream) | 200 | `{"v_id": 202, "stream_id": "333", "code": 0, "result": "OK"}` |

### Video Upload/Analysis - Reporting

#### Request

```text
[VOD Mode]
POST {callback_url}
Content-Type: application/json

{
  "v_id": 202,
  "stream_id": "VOD",
  "result": "OK",
  "code": 0
}

[Stream Mode]
POST {callback_url}
Content-Type: application/json

{
  "v_id": 202,
  "stream_id": "abc",
  "result": "OK",
  "code": 0
}
```

### Video Search - Request

#### Request

```text
POST http://{HOST}:{PORT}/api/v1/search_svc
Content-Type: application/json

{
  "v_id": 202,
  "stream_id": "ABC"
  "query": "A scene of a KT starting pitcher striking out a batter",
  "callback_url": "http://sbs.co.kr/"
}
```

The descriptions of each field are as follows

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `v_id` | int | O | Video to search |
| stream_id | String | X | The video’s stream_id. The server returns the received stream_id as-is; this is not intended to search only that specific stream |
| `query` | String | O | A sentence describing the scene you want to find (e.g., "home run," "comeback moment") |
| `callback_url` | String | X | Use this if you want to receive search results via a callback |

#### Response

```text
[If successful]
{"v_id": 201, "stream_id": "a", "search_id": "20260902-0001", "code": 0, "result": "OK"}

[If successful]
{"v_id": 201, "stream_id": "ABC", "search_id": "20260902-0001", "code": 0, "result": "OK"}

[No video available]
{"v_id": 201, "code": -1, "result": "Not found v_id"}

[Exceeded Capacity]
{"v_id": 201, "code": -1, "result": "busy, retry later"}

[Request Format Error]
HTTP 4XX
```

  
Field Descriptions

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| v_id | int | O | Key value for the entire video |
| stream_id | String | X | Return as-is if a stream_id exists |
| search_id | string | X | Issued when all search conditions are met |
| code | int | O | 0: Success, other: Failure |
| result | string | O | Status message |

### Video Search - View

#### Request

```text
[If successful]
POST {callback_url}
Content-Type: application/json

{
  "v_id": 202,
  "search_id": "20260902-0001",
  "query": "A scene of a KT starting pitcher striking out a batter",
  "result": "OK",
  "code": 0,
  "scenes": [
    {
      "stream_id": "ABC",
      "start_time": "01:12:33.4",
      "end_time": "01:12:48.9",
      "start_sec": 4353.4,
      "end_sec": 4368.9,
      "text": "[Top of the 5th]\nRun scored"
    },
    {
      "stream_id": "ABC",
      "start_time": "02:05:11.0",
      "end_time": "02:05:26.2",
      "start_sec": 7511.0,
      "end_sec": 7526.2,
      "text": "[Bottom of the 6th]\nStrikeout"

{
  "v_id": 202,

  "result": "fail",
  "code": -1,
  "scenes": []
}
```

```bash
HTTP 200 OK
```
