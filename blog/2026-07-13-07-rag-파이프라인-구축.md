---

- **RAG 파이프라인 = agent-scenario(색인) + agent-search(검색·생성)**

<!--truncate-->

```json
[색인 = Indexing 쪽]  agent-scenario
   영상 분석 결과 → 임베딩 → Milvus 4개 컬렉션에 upsert
        │
        ▼   (Milvus: segment / dialogue / scene / chapter)
        │
[검색·생성 = Retrieval + Generation 쪽]  agent-search
   질의 → 임베딩 → 벡터 검색(retrieve) → 맥락 확장(expand) → LLM 판정(select)

```
