### **개요**


<!--truncate-->


개발 과정에서 달마다 글을 블로그에 작성하기로 했다. 

Notion 글 작성까지는 확정이였으나, 퍼블릭 배포를 어떻게 할지가 고민이였다.

여러 후보 (Velog, Tistory) 가 있어서 동시에 해보다가, docusaurus 를 선택하였다.

![image](/img/blog/05-기술-블로그-개설/img-00.png)

docusaurus 는 Meta 에서 만든 오픈소스 프로젝트로, 다양한 기업에서 사용하고 있는 SSG (static site generator) 이다. 


공식 문서도 있고, 커뮤니티가 활달하며, 아래와 같은 아키텍처까지 볼 수 있다는 것에 놀랐다.

![image](/img/blog/05-기술-블로그-개설/img-01.png)

그 외에 Plugin, Routing, SSG (Static Site Generation), Client Architecture 까지 있다. 

아래에 참고 링크가 있다. 

참고 링크 : [https://docusaurus.io/docs/advanced](https://docusaurus.io/docs/advanced)

### Notion to Docusaurus 동기화

작성 글 퍼블릭 배포할 예정인 우리는, 아래 과정을 거쳐 동기화했다.

##### Notion 글 작성

- 협업 시 Notion 을 오랫동안 써왔기에, 일단 생각나는 대로 적기 시작했다

![image](/img/blog/05-기술-블로그-개설/img-02.png)

##### docusaurus config 설정 

- 공식 문서 참고 추천한다 ([https://docusaurus.io/ko/docs/cli](https://docusaurus.io/ko/docs/cli) )
- 우리의 url 과, github 페이지를 연결하였다.

![image](/img/blog/05-기술-블로그-개설/img-03.png)

##### Notion-to-md 이용 복사

- notion 내용 읽고, md 파일 만드는 과정이다
- Notion Token 발급 / 데이터베이스 별 ID 확인 필요하다
  ![image](/img/blog/05-기술-블로그-개설/img-04.png)

  ![image](/img/blog/05-기술-블로그-개설/img-05.png)

- notion_to_md.py 로, 서버에 아래와 같이 나타난다
  ![image](/img/blog/05-기술-블로그-개설/img-06.png)

##### workflow 이용 동기화

- build 와 deploy 과정으로 나누었고, 최종 목표로 commit / push 자동화 설정하였다. 
  - build: main branch 코드 읽기, md 파일 → 정적 파일 (HTML/CSS/JS) 로 변환 

  - deploy: [doc.scenemaker.solbox.com](http://doc.scenemaker.solbox.com/) 반영

### 동기화 결과

Notion 에서 보는 것과 완전 똑같이 나오는 것을 목표로 하였다.

![image](/img/blog/05-기술-블로그-개설/img-09.png)


생각보다 작업 시간이 많이 소요된 Docusaurus 이전 작업이였다.

기본적인 레이아웃과 테마 및 SEO 작업, 무엇보다 md 파일 작성이 가장 오래 걸렸다.


그래도 어느 정도 틀을 구축하니, 이후엔 속도가 붙기 시작하였으며, 매력적인 툴이라고 생각한다
